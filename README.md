# Garage KZ Autos

Site du Garage KZ Autos (Saint-Étienne) : accueil, prise de rendez-vous sur créneaux disponibles, espace gérant.

- Page unique `index.html` (HTML/CSS/JS sans outil de build).
- Base de données : Firebase (projet `kzautos-78773`, Firestore en Europe) + connexion e-mail/mot de passe du gérant.
- Règles de sécurité : à garder identiques à celles publiées dans la console Firebase (clients : réservation d'un créneau libre seulement ; gérant : tout le reste).
- Domaine : kzautos.generalmanagerapp.fr (fichier `CNAME`).
